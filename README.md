# РИТМ

**РИТМ** — «Решения, Исполнение, Трекинг, Медиа». Цифровая платформа для полного цикла работы Советов: от вопроса и протокола до исполнения поручения и публикации решения.

## Участники

- Министерство культуры, Министерство спорта, Министерство молодежной политики, Министерство образования.
- Совет по НТР, Совет по ССП, Совет по ДНЦ. Названия приведены в предоставленном пользователем виде без расшифровки сокращений.
- Специалист ОКМВ № 1 в демонстрационном интерфейсе — Лариса Яковлевна.

Председатель и секретарь автоматически подставляются в черновик сводного протокола при выборе Совета:

| Совет | Председатель | Секретарь |
| --- | --- | --- |
| ДНЦ | Глава ЛНР | Министр культуры ЛНР |
| НТР | Глава ЛНР | Заместитель министра образования и науки ЛНР |
| ССП | Председатель Правительства ЛНР | Представитель министерства образования и науки ЛНР |

Должности подставляются по умолчанию. Поля остаются редактируемыми для уточнения ФИО; ранее сохранённые значения не перезаписываются.

## Новые разделы

- **Повестка**: специалист выбирает Совет и министерство, указывает тему, докладчика, время доклада, обоснование и предложение в проект резолюции. Новый пункт сразу появляется в автозаполняемом черновике повестки и может быть исключён специалистом ОКМВ при фильтрации. Для НТР, ССП и ДНЦ подключены отдельные исходные формы DOCX; при переключении Совета меняются ссылка на форму и выгружаемая заполненная повестка.
- **Сводные протоколы**: отдельный черновик для каждого из трёх Советов автоматически наполняется одновременно с повесткой. По каждому пункту отражаются вопрос повестки, докладчик, предложение в резолюцию, срок реализации и ответственные за реализацию. Резолюция, срок и ответственные доступны для редакции секретарём. Доступны типовая форма DOCX, заполненный документ Word, печать и сохранение в PDF.
- **Медиа / Публикации по поручениям**: по министерству, Совету, тексту поручения, подтверждённому результату и источнику формируется проверяемый черновик новости. Публикация автоматически не выполняется.
- **Медиа / Редактирование**: черновик можно передать в общий редактор, изменить его текст и статус, оставить комментарии. В локальной версии изменения синхронизируются только между вкладками одного браузера и сохраняются в `localStorage`.
- **Медиа / Новости сферы**: предусмотрена единая лента по культуре, спорту, образованию и молодежной политике ЛНР. При работе через веб-сервер интерфейс опрашивает `news-feed.json` при открытии и каждые пять минут.

### Подключение новостей

`news-feed.json` содержит пустой массив и описание формата данных. Сервер-агрегатор должен получать публикации только из утверждённых официальных RSS/API-источников, проверять и дедублировать их, после чего формировать элементы со следующими полями:

- `category`: `culture`, `sport`, `education` или `youth`;
- `title`, `summary`, `source`;
- `published`: дата ISO 8601;
- `url`: ссылка на оригинальную публикацию.

При открытии `index.html` напрямую с диска автоматическая загрузка ленты недоступна из-за ограничений браузера. Нужны веб-сервер и серверный сборщик официальных новостей.

Данные этих двух разделов хранятся **только в localStorage данного браузера** и сохраняются при обновлении страницы. Это демонстрационная версия: предложения не видны пользователям на других устройствах, нет авторизации, общего сервера и утверждения официальных протоколов. Не вводите реальные персональные или конфиденциальные данные до внедрения защищённой системы. Обзорные метрики и другие старые карточки остаются демонстрационными.

## Что улучшено относительно исходного проекта

- Вместо четырех разрозненных модулей введен единый рабочий процесс и одна карточка решения.
- Добавлены приоритеты и прогноз риска по фактам активности, а не только проверка после дедлайна.
- Протокол стал точкой запуска поручений: исполнитель, срок и подтверждение фиксируются сразу.
- В медиа-мастерской сохранена автономия пресс-служб, но добавлены общий каркас, единый ритм и контроль SLA 24 часа.
- Метрики связаны с действиями: скорость цикла, доля исполнения, качество подтверждений и охват.
- Человеческий контроль сохранен на критичных шагах: согласование, перенос срока, проверка отчета и финальная публикация.

## Запуск

Открыть `index.html` в браузере. Презентация находится в `presentation.html`; листать стрелками клавиатуры или кнопками внизу.
